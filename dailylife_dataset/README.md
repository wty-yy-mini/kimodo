## Prompts generation from LLM

```txt
I need you to provide some relevant text prompts. These prompts will be passed to a model that will generate motion trajectories for the G1 humanoid robot based on the given text.

Please provide complete directional prompts around the last specified keyword. Each prompt will generate a 5-second action, so they need to be concise (covering daily states, up to 20 lines, no need to fill up).

Each prompt should be on one line (no need to number) and presented as a code block. Avoid using overly difficult words.

All trajectories must be generated on flat ground; do not describe the terrain. Do not specify the number of steps.

The total number of keywords is as follows; please distinguish between pairs of keywords:

1. locomotion
    1. walk
    2. run
    3. jump
2. transition
    1. stand
    2. turn
    3. sit
    4. squat
3. load
    1. lift

Current keyword: walk
```
