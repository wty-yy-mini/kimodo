# Daily Life Dataset

Used Kimodo to generate G1 motion retargeting dataset generated by text description.

## Text description

Generate with seed 1, Kimodo-G1-RP-v1, denoising steps 1000, num samples 5 per prompt, select the best by manual selection.

1. locomotion

## Prompts generation from LLM

```txt
I need you to provide some relevant text prompts. These prompts will be passed to a model that will generate motion trajectories for the G1 humanoid robot based on the given text.

Please provide complete directional prompts around the last specified keyword. Each prompt will generate a 5-second action, so they need to be concise (covering daily states, up to 20 lines, no need to fill up).

Each prompt should be on one line (no need to number) and presented as a code block. Avoid using overly difficult words.

All trajectories must be generated on flat ground; do not describe the terrain. Do not specify the number of steps.

The total number of keywords is as follows; please distinguish between pairs of keywords:

1. locomotion
    1. walk
    2. run
    3. jump
2. transition
    1. stand
    2. turn
    3. sit
    4. squat
3. load
    1. lift
    2. push
    3. throw

Current keyword: walk
```

## Dataset Generation Script

Use `dailylife_dataset/generate_data.py` to generate G1 NPZ data from each keyword's `prompts.txt`.

- Config file: `dailylife_dataset/config.py`
- Default generation settings:
  - seed = 1
  - model = `Kimodo-G1-RP-v1`
  - denoising steps = 1000
  - num samples = 5 per prompt
  - duration = 5.0 seconds
- Output location: same folder as `prompts.txt`
- Output filename: `{prompt_line_id}_{sample_id}.npz`
- Skip rule: if any existing `{prompt_line_id}_*.npz` exists, that prompt is skipped
- NPZ keys (tiny format): `root_positions`, `root_rot`, `dof`, `fps`, `prompt`

Examples:

```bash
# Generate default keywords from config.py
python dailylife_dataset/generate_data.py

# Generate only selected keywords
python dailylife_dataset/generate_data.py --keywords walk run throw

# Force regeneration even if prompt-id files already exist
python dailylife_dataset/generate_data.py --keywords walk --overwrite
```
